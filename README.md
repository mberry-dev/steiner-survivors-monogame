# Steiner Survivors

A 2D survival game built in C# using the MonoGame framework.

## About
Steiner Survivors is a team-built 2D survival game where players fight to stay alive against waves of enemies. Built as part of a three-person team over a single semester.

## My Contributions
- Built the game state system (start, pause, and resume states)
- Designed and implemented the main menu and settings menu
- Added remappable controls so players can customize keybindings
- Integrated the in-game music system

## Built With
- C#
- MonoGame

## How to Run
1. Clone the repo
2. Open the solution in VS Code
3. Build and run the project
